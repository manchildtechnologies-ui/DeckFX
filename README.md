
# DeckFX
Stream Deck Fun


DeckFX is a high-performance real-time graphics engine and visual editor for Elgato Stream Deck devices, featuring GPU-powered effects, audio visualization, video playback, desktop capture, scene management, an extensible plugin architecture, and a modern creator-focused workflow.
